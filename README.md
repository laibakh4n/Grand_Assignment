# Riscv-log-analyzer

A shell-based tool that analyzes RISC-V simulation log files
oand generates summary reports.

---

## Description

This tool reads simulation log files generated by RISC-V test 
suites, counts PASS, FAIL and SKIP results, and produces a 
clean summary report. Built using Bash, grep, awk and Make.

---

## Requirements

- Ubuntu 22.04+
- bash, grep, awk, sed, git

Check all requirements:
```bash
./scripts/setup_env.sh
```

---

## Installation

```bash
git clone <your-repo-url>
cd riscv-log-analyzer
chmod +x scripts/*.sh
```

---

## Usage

Run on a single log file:
```bash
./scripts/analyze.sh test_data/sample_fail.log
```

Generate full report for all log files:
```bash
./scripts/generate_report.sh
```

---

## Make Targets


| Target       | Description                        |
|--------------|------------------------------------|
| make all     | Run analyzer on all log files      |
| make test    | Run tests and verify output        |
| make report  | Generate report in output/         |
| make clean   | Remove all generated files         |
| make setup   | Check all required tools           |
| make help    | Show all available targets         |
